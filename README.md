# Noctis View

Meta Display-oriented camera switching web app prototype.

- Starts on **FORWARD**.
- Swipe left/right to cycle **Forward → Right → Rear → Left**.
- Returning to the page resets to **FORWARD**.
- `Test video` uses the browser camera when permission/support is available.
- External Raspberry Pi camera feeds can be wired into `app.js` later.
